torch.nn.functional.dropout

Official docs URL: https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.dropout.html

torch.nn.functional.dropout(input: torch.Tensor, p: float = 0.5, training: bool = True, inplace: bool = False) -> torch.Tensor

During training, randomly zeroes some elements of the input tensor with probability p.
Uses samples from a Bernoulli distribution.
See torch.nn.Dropout for details.
Args:
    p: probability of an element to be zeroed. Default: 0.5
    training: apply dropout if is True. Default: True
    inplace: If set to True, will do this operation in-place. Default: False
