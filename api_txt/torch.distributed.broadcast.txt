torch.distributed.broadcast

Official docs URL: https://docs.pytorch.org/docs/stable/generated/torch.distributed.broadcast.html

torch.distributed.broadcast(tensor: torch.Tensor, src: int | None = None, group: torch.distributed.distributed_c10d.ProcessGroup | None = None, async_op: bool = False, group_src: int | None = None)

Broadcasts the tensor to the whole group.
tensor must have the same number of elements in all processes
participating in the collective.
Args:
    tensor (Tensor): Data to be sent if src is the rank of current
        process, and tensor to be used to save received data otherwise.
    src (int): Source rank on global process group (regardless of group argument).
    group (ProcessGroup, optional): The process group to work on. If None,
        the default process group will be used.
    async_op (bool, optional): Whether this op should be an async op
    group_src (int): Source rank on group.  Must specify one of group_src
        and src but not both.
Returns:
    Async work handle, if async_op is set to True.
    None, if not async_op or if not part of the group
