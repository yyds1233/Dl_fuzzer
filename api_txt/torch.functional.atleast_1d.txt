torch.functional.atleast_1d
Official reference URL: https://docs.pytorch.org/docs/stable/generated/torch.functional.atleast_1d.html

Returns a 1-dimensional view of each input tensor with zero dimensions.
Input tensors with one or more dimensions are returned as-is.

Args:
    input (Tensor or sequence of Tensors): tensor(s) to be converted to at least 1-dimensional.

Returns:
    output (Tensor or tuple of Tensors)

Example::

    >>> x = torch.arange(2)
    >>> x
    tensor([0, 1])
    >>> torch.atleast_1d(x)
    tensor([0, 1])
    >>> x = torch.tensor(1.)
    >>> x
    tensor(1.)
    >>> torch.atleast_1d(x)
    tensor([1.])
    >>> x = torch.tensor(0.5)
    >>> y = torch.tensor(1.)
    >>> torch.atleast_1d((x, y))
    (tensor([0.5000]), tensor([1.]))
    >>> torch.atleast_1d()
    ()
