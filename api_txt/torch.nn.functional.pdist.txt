torch.nn.functional.pdist

Official docs URL: https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.pdist.html

torch.nn.functional.pdist(input, p=2) -> Tensor

Computes the p-norm distance between every pair of row vectors in the input.
This is identical to the upper triangular portion, excluding the diagonal, of
`torch.norm(input[:, None] - input, dim=2, p=p)`. This function will be faster
if the rows are contiguous.
If input has shape N x M then the output will have shape
(1 / 2) N (N - 1).
This function is equivalent to scipy.spatial.distance.pdist(input,
'minkowski', p=p) if p in (0, inf). When p = 0 it is
equivalent to scipy.spatial.distance.pdist(input, 'hamming') * M.
When p = inf, the closest scipy function is
scipy.spatial.distance.pdist(xn, lambda x, y: np.abs(x - y).max()).
Args:
    input: input tensor of shape N x M.
    p: p value for the p-norm distance to calculate between each vector pair
        in [0, inf].
