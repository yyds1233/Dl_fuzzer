torch.nn.init.uniform_

Official docs URL: https://docs.pytorch.org/docs/stable/generated/torch.nn.init.uniform_.html

torch.nn.init.uniform_(tensor: torch.Tensor, a: float = 0.0, b: float = 1.0, generator: torch._C.Generator | None = None) -> torch.Tensor

Fill the input Tensor with values drawn from the uniform distribution.
mathcalU(a, b).
Args:
    tensor: an n-dimensional `torch.Tensor`
    a: the lower bound of the uniform distribution
    b: the upper bound of the uniform distribution
    generator: the torch Generator to sample from (default: None)
Examples:
    >>> w = torch.empty(3, 5)
    >>> nn.init.uniform_(w)
